Not the Amazon Bee product

This is a local test stand‑in we wrote ourselves. It is not Amazon Bee.

Amazon ships no simulator or developer feed for the Bee wearable, so there is nothing official to point a trust‑boundary test at. This page exists so we can try that boundary with live, improvised speech — including a second bystander voice — instead of only a fixed test fixture.

It runs entirely on this laptop, sends nothing to Amazon, and produces no Amazon data. When we demo the real wearable we use the real CLI. Everything you see here was spoken into a phone microphone.

    Privacy note — read this before you record anyone

    • Your voice leaves this phone. Browsers implement Web Speech by streaming audio to the browser vendor's servers (Google for Chrome and Edge, Apple for Safari) to do the recognition. This is not end‑to‑end encrypted, and this page does not work offline.
    • That is weaker than the real device, and we will not pretend otherwise. The wearable transcribes on‑device, so its audio stays with you. This stand‑in has no such guarantee — it inherits the browser's, and the browser's is weaker.
    • Transcripts stay in memory only. This page writes nothing to disk. Turns live in the local store process and in this page's DOM, and the store is in‑memory too, so a server restart clears them. The only thing persisted anywhere is your token, in localStorage, and the Forget button below removes it.
    • Only record people who know. Speech recognition picks up the whole room. Say out loud that you are recording, and get consent before you press the mic.
    What this page is and is not
    • A local stand‑in written for our own testing. Not Amazon Bee, not a mock‑up of it, not affiliated with or endorsed by it.
    • It exists because Amazon ships no simulator for the wearable, so a trust‑boundary test would otherwise run only against a fixed fixture.
    • It calls a local server on this machine at /ingest and /state. It sends nothing to Amazon and no product data.
    • Recognition quality is the browser's, not ours, and it will sometimes mishear. The demo is about the trust boundary, not about transcription accuracy.
