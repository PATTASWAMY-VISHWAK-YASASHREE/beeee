        Why this is safe

        • Third-party speech is not instruction. Recalled text is wrapped in a nonce fence before it leaves the server, and a delimiter an attacker injects is neutralised rather than trusted.
        • Reported, never obeyed. Instruction-shaped text raises a warning, and the notes are shown rather than swallowed.
        • Read-only by construction. The allow-list is enforced in the client before a request leaves the process, so no recalled text can reach an action.

        Connection

        Serve this page from the bridge itself (npm run start:bee, then open http://127.0.0.1:8791/). Opened as a file:// page the browser blocks the calls, because the bridge is deliberately local-only and sends no CORS headers.
