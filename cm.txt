Align the Node engine floor with the types, and with vitest

The audit suggested pinning @types/node to ^20 to match a declared engine
floor of 20.11. Applying that half of the suggestion broke a clean install:
vitest 5 declares @types/node ^22 || >=24 as a peerOptional dependency, so a
fresh clone could not resolve at all. The local install only succeeded because a
lockfile already existed - which is exactly the class of bug a clean-clone check
exists to catch.

The mismatch is real, so it is resolved by moving the floor rather than lowering
the types: engines now requires >=22.12.0, which matches @types/node ^22 and
vitest 5, and Node 22 is an LTS line. The types and the declared support now
describe the same thing.
